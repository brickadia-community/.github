Tools

Brickadia EA3 removed support for the BRS format. To load BRS saves, switch Brickadia to its archive-ea2 branch on Steam, or upgrade them to BRZ with brs2brz.

  • BrickCartographer

    View BRS, BRDB and BRZ maps.

    SiteRepo
  • heightmap2brz

    Builds saves from heightmaps and colormaps. Also works as img2brz and img2text.

    SiteRepo
  • mc2brsBRS

    Converts Minecraft worlds to BRS saves.

    Repo
  • BrickadiaAutoPainter

    A robot that paints images for you in game.

    Repo
  • palette

    Create, convert and import Brickadia color palettes.

    SiteRepo
  • rbxl-brsBRSArchived

    Converts Roblox saves (RBXLX) to BRS.

    Repo
  • textured-voxelizerBRS

    Voxelizes OBJ models into BRS saves. For BRZ, see obj2brz.

    Repo
  • brs.world

    A save preview website.

    Repo
  • img2brsBRS

    Converts images to saves.

    Repo
  • brs2brz

    Converts BRS saves to BRZ without opening the game.

    Site
  • wirescript

    A language that compiles code to Brickadia's logic gates.

    SiteDocsRepo
  • bls2brz

    Converts Blockland saves (BLS) to BRZ.

    SiteRepo
